# Folder Merger

Лёгкая Windows-программа с тёмной темой, которая рекурсивно собирает все файлы из выбранной папки в один текстовый файл. Написана на Python и tkinter — никаких внешних зависимостей.

## Возможности

- **Рекурсивный обход** — проходится по всем вложенным папкам, собирает файлы, сортирует по алфавиту и пишет в один выходной файл
- **Исключения** — можно исключить файлы или папки по имени, с указанием области (везде, только корень, или в конкретной подпапке); общие исключения действуют для всех папок
- **Тёмная тема** — современный тёмный интерфейс
- **Один экземпляр** — запускается только одна копия программы, повторный запуск игнорируется
- **Логирование сессий** — хранит историю последних 10 запусков в папке `logs/`
- **История папок** — запоминает до 20 недавно использованных папок

## Требования

- Windows 7+
- Python 3.11+ (tkinter входит в комплект, ничего дополнительно ставить не надо)

## Установка

```bash
git clone https://github.com/username/folder-merger.git
cd folder-merger
```

## Запуск

```bash
python main.py
```

Или просто дважды кликнуть `run.bat` — откроется без консоли.

### Как пользоваться

1. Выберите исходную папку (или выберите из истории)
2. Укажите путь к выходному файлу
3. При желании настройте исключения через кнопку «Настроить исключения»
4. Нажмите «Запустить»

В результате получите файл, где содержимое каждого файла из исходной папки идёт по порядку, а перед каждым файлом указан его относительный путь.

## Формат вывода

```
================================================================================
Файл: relative/path/file.txt
================================================================================

[содержимое файла]

===============================================================================
Файл: relative/path/next_file.txt
===============================================================================

[содержимое файла]
```

## Настройки

При первом запуске настройки создаются автоматически. Можете скопировать `config/settings.example.json` как образец.

| Параметр | Описание |
|---|---|
| `last_folder` | Последняя использованная исходная папка |
| `folder_history` | История папок (макс. 20) |

Исключения хранятся отдельно:

- `config/global_exceptions.json` — общие исключения для всех папок (по умолчанию: `logs`, `dumps`, `__pycache__`, `.git`, `node_modules`, `*.tmp`, `*.log`, `Thumbs.db`, `.DS_Store`, `.gitignore`, `*.md`)
- `config/local_exceptions.json` — исключения для конкретных папок (в гитигноре, содержит локальные пути)

│   ├── instance_manager.py       # Контроль единственного экземпляра
│   ├── logger.py                 # Логирование сессий
│   └── theme.py                  # Цвета тёмной темы
